# UI-тестирование учебного сервиса "Stellar Burgers"
Проект автоматизации UI‑тестирования веб‑приложения с использованием Selenium WebDriver и pytest.

## Используемые технологии:
* Python 3.14.7
* Selenium 4.54.0
* Pytest 9.2.0

## Установка зависимостей:

1. Создайте виртуальное окружение: Windows "python -m venv .venv"
2. Активируйте окружение "source .venv/Scripts/activate"
3. Установите зависимости "pip install -r requirements.txt"

## Запуск тестовых файлов с помощью команды:
* pytest -v
